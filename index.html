About

From Pascal to AI-powered automation.

My name is Lukáš and I've been into computers since I was a kid. I started programming in 2012 – my first languages were Pascal and C++, but I didn't stick with them for long.

Today I develop backends for all kinds of applications, mostly REST APIs. I work primarily in PHP and my framework of choice is Symfony. Over the last five years I've worked mostly as a freelancer – building APIs for internal systems and designing the architecture of the applications I deliver. On the frontend I use React and Tailwind, and I'm an active Linux user and administrator.

I also take care of the whole road to production. I package applications into Docker containers, build CI/CD pipelines that test, analyse and deploy every change automatically, and keep them running reliably on Linux servers.

Lately I've been focusing on AI – integrating large language models into applications, building AI agents, automating business processes and using AI to speed up the whole development workflow. I'm also into web application security and want to grow further towards penetration testing and vulnerability analysis.
